# State files and t0_state sections the T0 role relies on, and the code that
# really writes them. Read by scripts/lib/t0_role_sources_audit.py, which
# t0_role_audit.sh --static runs.
#
# Format: target | writer script (repo-relative) | marker | role phrase
#   target       path under the project state directory, or <file>#<section> for a
#                top-level section of a state file
#   marker       literal that must occur in the writer (the file name, or the
#                quoted section key)
#   role phrase  optional: text the role must still contain (sections only;
#                DISPATCH_RULES is checked for writers, not for phrases)
#
# Two-way coupling: a state path the role names that is missing here is
# STATE-UNWRITTEN. An entry whose writer no longer holds the marker is
# STATE-WRITER-GONE. Removing a writer or a section therefore forces an edit
# to this file, and the role edit that goes with it.
