# learning-loop-sluiten: A scheduled, observable learning loop

Nightly learning produces a shadow report and health beacon from receipt failures and open-item signals. Review gates stay independent of injected learning, and persistent learning or dream activation still requires an operator decision.

## How

Run `vnx learning status` from the project checkout; use `vnx learning --help` for available actions and flags. Follow the [learning review ritual](../intelligence/SELF_LEARNING_LOOP.md#review-ritual-proposal--activation) before applying proposals.
