# poort-is-bewijs: Review decisions become usable merge evidence

A REVISE judgment cannot satisfy a required passing review seat. Review checks are published to the project’s repository, and the merge path requires the applicable seats’ evidence on the PR head.

## How

Follow [review gate verification](../operations/T0_RUNBOOKS.md#34-review-gate-verification) to check the result and report, then the [forge gate runbook](../operations/FORGE_GATE.md) for repository protection and merge authorization.
