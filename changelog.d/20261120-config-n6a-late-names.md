- Config: eleven environment variables are deleted and no longer change behaviour (ADR-087, config-een-oppervlak N6a, dlv-c6907e6ad908). Each keeps the path the code took when it was unset: `VNX_POOL_LEASE_HEARTBEAT_SECONDS` (pool lease renewal is every 15 s, `LEASE_HEARTBEAT_DEFAULT_S`); `VNX_LITELLM_AGENTIC_MAX_TURNS`, `_MAX_TOKENS`, `_CMD_TIMEOUT` and `_DEADLINE` (an agentic LiteLLM run uses 30 turns, 8192 tokens, 120 s per command and 1800 s in total unless the caller passes a value); `VNX_LEARNING_LOOP_CUTOFF` (the learning loop ignores receipts before `DEFAULT_RECEIPT_CUTOFF`, 2026-09-28T16:41:11Z); `VNX_MODE_GATING_ENABLED` (the command gate per mode always runs once `mode.json` exists); `VNX_STARTER_MODE_ENABLED` (`vnx init --starter` always works; `vnx_mode.FEATURE_FLAGS`, `is_feature_enabled` and `check_mode_feature_enabled` are removed); `VNX_PROVIDER` (`vnx start` takes the T0 provider from `VNX_T0_PROVIDER`, default `claude_code`); `VNX_WORKTREES` (the "Ignoring VNX_WORKTREES=true" log line is gone; start never made worker worktrees); `VNX_VENV_PATH` (the venv comes from `PROJECT_ROOT/.venv`, then the main worktree). Differences from before: someone who set one of these to a non-default value now gets the default; an unparseable learning-loop cutoff can no longer come from the environment.
