- `scripts/ci/test_shard_plan.py` is a project-independent test shard planner for the Profile A split (`pr-ci-onder-zes-minuten` C2a). `plan` assigns test files to N shards greedily on duration (heaviest file into the lightest shard, ties to the lowest shard), reads durations from JUnit-XML (`classname` mapped to the input file, or the `file` attribute), and sends a file without a duration to `sha256(path) % N + 1`. `select-source` takes the JUnit-XML of the artifact of the newest successful run of a workflow on a branch created before a given timestamp via `gh api`. Any source failure gives `"source": "hash"` with the reason, a complete plan, exit 0; N < 1 or an empty list exits 2. No workflow uses it yet.
