- ADR-089 records the platform decision (B-20261118-ee6c4aae): Linux is a full platform for every user path (`vnx init`, `vnx dispatch`, the merge door, the review gates, the receipt-processor), Windows is supported through WSL2, native Windows is out of scope (353 `fcntl` lines in 97 files, 1,096 `tmux` lines and 179 shell scripts in the fabric are POSIX), and the Linux CI runner is where the platform is measured. Goal and current state are kept apart: the macOS-only constructs INV-A counts go to the follow-up track `linux-gebruikerspad`, and there is no "Linux full platform" claim for 2.0 before it is done (agnostisch-standaard ADR-P).
