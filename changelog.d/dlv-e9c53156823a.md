- Review gates (reviews-zonder-uitkomst D4a): a reviewer run now counts toward its obligation's per-head retry cap (`head_runs`) wherever it starts, booked once in `GateExecutor.execute_gate` under the run lock (`gate_run_guard.book_reviewer_run`). A run started by hand through `review_gate_manager.py request-and-execute` is counted too; it is never refused at the cap, the obligation runner still enforces the cap before its own launches. The runner no longer books the count itself, so its own runs are counted once.
