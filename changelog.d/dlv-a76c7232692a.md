- New `scripts/lib/steering_proposal_store.py` (ADR-072, operator-bijsturing-leert OB-5a): the store of steering proposals. A proposal id is `sha256(project_id | oorzaak | artefact_soort | doelpad)[:16]` and the text is a revision under it. Decisions and reopen records are append-only (`steering_proposal_decisions.ndjson`, fsynced first), `steering_proposals.json` is a projection rebuilt from them. A rejected proposal returns only with a prompt timestamped after the rejection; otherwise `reconcile()` counts it as `suppressed_rejected`. An unreadable record file is refused, never read as empty. Nothing here applies a proposal.
