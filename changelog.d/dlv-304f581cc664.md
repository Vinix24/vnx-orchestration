- ADR-045 (audit-spoor-kern K-8): a worker report for a **v3** dispatch is now booked as one `report_ingested` line instead of a `task_complete`, on every converter path — the clean path, the declared-failure/kill path, the contract-invalid path and the fail-closed rejection path. The line carries the same payload the task-shaped receipt carried, plus `project_id` and `attempt`, and exactly one link: `end_outcome_id` when `dispatch_lifecycle.finalize` already wrote the attempt's end line, else `end_pending: true`; it is never rewritten later. One helper, `scripts/lib/report_lifecycle_mode.decide` (`v3` from the dispatch row's `metadata_json.lifecycle_mode` or from a `dispatch_started` with `lifecycle_mode: v3`, latest start line first, a v3 answer stays v3), is called by both `report_to_receipt_converter` (scan, public builder, `restore_stranded_reports`) and `report_parser`. When the decision or the attempt cannot be established, both writers book nothing and refuse loudly with the dispatch id and the reason, leaving the report retryable. Legacy dispatches — and every dispatch while `ledger_lifecycle` is off with no v3 row or start line — keep byte-identical receipts.
