- Worktree cleanup (track `worktree-opruiming-structureel`, PR-2): `scripts/lib/worktree_salvage.py` preserves a dirty dispatch worktree before a later PR removes it: a thin bundle of the local-only commits, a staged patch (`HEAD` to index) and a worktree patch (index to worktree) kept apart so a staged change the tree undoes again is not lost, a tarball of untracked files with the `.venv`-style internal symlinks left out, and one appended `MANIFEST.txt` line in the 27-09 hand-salvage format. Whether there is tracked work comes from `git status`, not from an empty diff; unmerged paths and a status change no diff carries are refused. Dry-run by default; `verify()` names every artifact that is missing, empty or unreadable, and every patch that does not apply in order to the salvaged head (checked in a scratch index that writes nothing into the repository). Only an empty result may gate a removal. No caller yet.
