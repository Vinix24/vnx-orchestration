- A refused refire is no dispatch outcome (OI-2536): when the door refuses a fire because another attempt of the same dispatch is still live (`refire_attempt_live`), its one `blocked`/`delivery_refused` receipt now carries `refusal_scope: "fire"`, and the dispatch-register emitter writes no outcome event for it — the register keeps the live attempt's `dispatch_started` instead of a `dispatch_failed`, so `t0_decision_reconcile` no longer resolves the pending decision as failed. The receipt itself is unchanged (ADR-005 keeps the decision in the ledger) and every other start refusal (`base_ref_unresolved`, `consumer_root_unresolved`, `ledger_corrupt`, ...) still reads exactly as before.
