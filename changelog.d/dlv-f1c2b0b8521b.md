- Every event-archive writer in `event_store.py` (copy, run-stream move, late append, end-of-run archive, boundary rotation, size rotation) now goes through one write boundary, `_write_archive`. It takes `<archive_dir>/.archive.lock` after the writer's lock on the live stream, resolves the archive the id already has, and adds new lines to a `.ndjson.gz` as a new gzip member (deduplicated) instead of creating a plain beside it. `open_archive_text` falls back once to `<id>.ndjson.gz` when the plain file is gone (eventarchief-compressie C1, ADR-081).
