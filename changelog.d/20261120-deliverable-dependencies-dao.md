- `scripts/lib/deliverable_dependencies.py`: the DAO for order between deliverables (ADR-096 §1-2, B1b): `depend` (hard by default, soft on request) refuses an unknown id on either side and a cycle over the active rows (a self-edge counts), `undepend` keeps the row with `removed_at` and a required reason, `dependencies` lists both directions; every change writes a `coordination_events` row and must run inside the caller's transaction. The CLI forms follow in B1c.
