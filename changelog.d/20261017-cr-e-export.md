- Context-rotation plugin, deliverable E: `scripts/maintenance/export_toolkit_plugin.sh` exports a merged commit's tracked `packages/claude-code-toolkit/context-rotation` files into a local clone of the public toolkit repo, as one commit on the branch `export/context-rotation-<version>` with the exact bytes and modes of the source. The script never checks out, writes into, resets or cleans the clone's working tree or index. It builds the commit in a temporary worktree of its own outside the clone, with none of the clone's hooks, on the existing export branch or else on the commit the clone's checkout is on. The branch is the only thing it writes in the clone: last, as a compare-and-swap. It syncs deletions inside the plugin folder only, merges only the `context-rotation` entry into `.claude-plugin/marketplace.json` (other entries stay byte-for-byte) and adds the README row to the `## Tools` table once. It refuses a commit that is not on `origin/main`, a source folder with a link, an operation in progress in the clone's checkout, an export branch that a worktree has checked out or is rebasing or bisecting, a link on the base where it writes, a version that differs between `plugin.json`, the marketplace entry and `--tag`, and a content change without a version bump (a mode change counts). Before the branch is written it runs the plugin's leak patterns over the committed blobs, also when there is nothing to export, and names a hit the base's marketplace file or README already had as pre-existing. A failure removes the temporary worktree and swaps the branch back; when it cannot, it exits 3 and lists what is left. It never pushes or tags. POSIX sh, excluded from the wheel. The plugin gets a `README.md` with the maintainer runbook.
