- Context-rotation plugin, deliverable E: `scripts/maintenance/export_toolkit_plugin.sh` exports a merged commit's tracked `packages/claude-code-toolkit/context-rotation` files into a local clone of the public toolkit repo on the branch `export/context-rotation-<version>`. Everything it writes is built from that branch's own base commit, never from the clone's working tree, so a re-export from `main` keeps what the export branch already carries. It syncs deletions inside the plugin folder only, with NUL-separated listings so a quoted file name is removed too, merges only the `context-rotation` entry into `.claude-plugin/marketplace.json` (other entries stay byte-for-byte), adds the README row once, and commits exactly its three paths. It refuses a commit that is not on `origin/main`, a source folder with a link, a clone with any staged, unstaged or untracked change or an operation in progress, a link or an ignored file where it writes, a version that differs between `plugin.json`, the marketplace entry and `--tag`, and a content change without a version bump. It re-runs the plugin's leak patterns on the target and names a hit the base already had as pre-existing. Every exit that is not a successful export puts the clone back on the ref, commit and branches it had, and checks that; when it cannot, it exits 3 and lists what is left. It never pushes or tags. POSIX sh, excluded from the wheel. The plugin gets a `README.md` with the maintainer runbook.
