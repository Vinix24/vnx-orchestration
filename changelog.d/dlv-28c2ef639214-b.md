- Deleted the environment variable `VNX_T0_ROTATION` (config-een-oppervlak, ADR-087). It gated the Stop hook `scripts/hooks/session_stop_rotation.py`, which was a no-op wherever the variable was unset (it is set nowhere); the hook, its `.claude/settings.json` Stop entry and its tests are gone, so a Stop writes no handoff. Fixed value that now holds: the unset one (no handoff on Stop). The live T0 rotation (`scripts/t0_rotate_spawn.sh`, `scripts/lib/t0_rotation_state.py`, `scripts/hooks/t0_context_guard.py`) never read it and is unchanged; the T0 identity check `_is_t0_session` moved into `t0_context_guard.py` with the same logic. The only difference with today is that the override is gone.
