- Codex lane (config-een-oppervlak PR-2s, ADR-087): three env switches are deleted. The codex lane now
  always does what it did with them unset. Nothing changes except that exporting one of them no longer
  has any effect.
  - `VNX_CODEX_SANDBOX`: `codex_spawn` always builds `codex exec --json --dangerously-bypass-approvals-and-sandbox --model <m>`,
    the bypass route in an isolated worktree. The permission record keeps `layer0.sandbox: bypass` and
    `layer1.fs: unsupported`; `permission_harness_map` keeps codex `filesystem_read`/`filesystem_write`
    at DEGRADED and now names the bypass route as the reason instead of the deleted variable.
  - `VNX_CODEX_STALL_THRESHOLD`: `spawn_codex` uses its `chunk_timeout` argument (default 60 s), always
    scaled with the deadline by `coerce_chunk_stall` (OI-903); `CodexAdapter` uses the context's
    `chunk_timeout` or 60 s; the `codex_gate` stall threshold in `headless_adapter` is fixed at 300 s
    (`GATE_STALL_DEFAULTS`).
  - `VNX_CODEX_TIMEOUT`: `spawn_codex` uses its `total_deadline` argument (default 600 s); `CodexAdapter`
    uses the context's `total_deadline` or 300 s; the codex classifier provider uses its
    `timeout_seconds` argument or 120 s.
