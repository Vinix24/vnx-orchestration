- `scripts/ci/profile_a_aggregate.py decide` is the fail-closed decision of the Profile A aggregator (`pr-ci-onder-zes-minuten` C3, precursor a). It reads `${{ toJSON(needs) }}` and is green only in mode `light` (every shard `success` with profile `light`), `sharded` (every shard `success` with profile `heavy` and evidence under `shard-k/`) or `serial` (`VNX_CI_XDIST=0`, every shard `skipped`), always with the guards job `success`. Anything else exits 1 and the verdict lists every reason; invalid input exits 2; only exit 0 prints `mode=<mode>`. No workflow uses it yet.
