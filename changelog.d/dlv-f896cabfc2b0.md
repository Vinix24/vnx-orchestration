- Deltareview (DR-1): `scripts/lib/review_findings.py` gives every review finding a stable 16-hex id — `sha256(seat, path, symbolic context, normalised text)`, no line number in it — plus the pure status model (`open`, `fixed`, `waived`, `regressed`, `unverifiable`) where an unanswered id stays `open`, a vanished anchor is `unverifiable` and `waived` is only carried from the previous status; `blocks()` marks `open`, `regressed`, `unverifiable` and any unknown status as blocking. No IO, no caller changes.
