- The cost ledger no longer leaves a line open for the old writer, and no longer prices unknown usage as zero (dispatch 20261020-kp-k2a1-r3, round 3 on #2141, ADR-043).
  Every time `cost_ledger` holds the ledger lock, the replay's already-landed branch and a queued record included, it first
  ends a last line without `\n` and fsyncs. A record that landed whole but without its newline is ended before its spool
  file is removed, so `emit_provider_cost` can no longer glue its next line onto it. An append that fails halfway ends its
  own line at once when the disk has room.
  A metered run whose `input_uncached`, `output` or a cache count its price charges is `null` gets `cost_usd: null` and
  `unavailable:usage_unknown`, and `aggregate_runs` lists it under `unavailable`. A count that is a real 0 stays a priced zero.
