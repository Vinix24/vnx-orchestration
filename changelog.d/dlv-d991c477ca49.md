- Ledger corruption (ADR-045 K-9c, track `audit-spoor-kern`, OI-2528): a broken line inside `t0_receipts.ndjson` is a named refusal on every reader that decides whether one attempt already started or already ended — but only where that line is this dispatch's own evidence. The torn tail (a crash mid-append: the final fragment, unterminated) stays no record and no evidence.
  - `scripts/lib/ndjson_io.py` gains the one torn-tail rule as `scan_ndjson_lines` plus `read_ndjson_strict_bytes`; `read_ndjson_strict` takes an optional relevance predicate on the raw line. A broken line is torn only if it is the final fragment of what was read AND not newline-terminated: a final broken line that does end in a newline is committed corruption, including one carrying invalid UTF-8. With a predicate, only a matching broken line raises and the others are skipped with a WARNING; without one, the strict reader keeps K-8a r3's whole-file refusal.
  - The door (`dispatch_start._lifecycle_lines`) refuses `StartRefused("ledger_corrupt", line N)` when an interior broken line carries this `dispatch_id`; the prefilter and exact-key check stay. The finalizer (`dispatch_lifecycle._end_lines_from_offset`) refuses `AppendReceiptError("ledger_corrupt")` on the same scope, appends nothing and leaves the end intent for recovery. The append layer's tail scan (`find_prior_end_line`) keeps dropping a window cut and tolerating a torn final line, and refuses `lifecycle_end_lookup_failed` with a reason starting `ledger_corrupt` for any other broken line naming the receipt's dispatch id.
  - The sweep's scan (`v3_in_flight`) reports every interior broken line as `ledger_corrupt line N` in the error list the count already surfaces, and a run whose scan saw one writes no `abandoned` end: it fails through the existing heartbeat path, so the ledger stays byte-identical. The K-9 lifecycle count keeps its whole-ledger `unmeasured` answer.
  - The report decision (`report_lifecycle_mode._read_ledger`) moves from the whole-ledger refusal to the same dispatch scope, keeping `ledger_corrupt` with the line number. A store path that exists but is not a regular database file is now `ROW_UNREADABLE` and refuses, never `legacy` (OI-2529); only a path that does not exist stays absent.
