- Removed `VNX_ALLOWED_SIGNERS` and `VNX_ATTEST_OVERRIDE_BUDGET` (ADR-087, one configuration surface). The signer list now comes only from the signer files: `.vnx-attest/allowed_signers` at the base branch, else `.vnx-attest/allowed_signers` or `.vnx/allowed_signers` in the working tree. The attest override budget is the constant `DEFAULT_OVERRIDE_BUDGET` = 5 per rolling 30-day window. The only behaviour change: a set variable no longer has any effect. An operator who pointed `VNX_ALLOWED_SIGNERS` at a file outside the project (for `vnx horizon plan-gate sign`) puts that signer line in `<project>/.vnx-attest/allowed_signers` (gitignored) instead.
